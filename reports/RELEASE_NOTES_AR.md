# ملاحظات نسخة ESKO ذات الأقسام الستة

## واجهة موحدة
- شريط سفلي ثابت من ستة عناصر بالترتيب: البيت، المتجر الإلكتروني، المستودعات، المساعد، الأقسام، الحساب.
- واجهات متجاوبة RTL مع safe-area padding وحالة نشطة ودلالات وصول.
- تم توحيد ملفات shell/controller/styles في `public/` و`docs/` و`docs/v501/` ومرشح Android V9.0.2.

## وظائف مفعلة في نسخة العمل
- موجز منشورات من الخادم مع بحث وتصنيف نص/صورة/فيديو، إنشاء منشورات نصية أو روابط HTTPS، إعجابات محددة المعدل، تعليقات، مشاركة، إبلاغ ومنع تكرار البلاغ المفتوح، وحذف المالك لمنشوره.
- حفظ المسودات محليًا في IndexedDB.
- المتجر يقرأ المنتجات المنشورة من الخادم ويحتفظ بسلة محلية. الدفع وإدارة المخزون والطلبات غير مفعلة.
- المستودعات خاصة بالحساب، مع إنشاء مشروع وحفظ/قراءة/تعديل/تنزيل/حذف ملفات نصية. لا يتم تنفيذ ملفات المستخدم على الخادم.
- المساعد قواعد محلية محدودة؛ لا نموذج توليدي أو RAG متصل.

## حدود غير مكتملة
- الصور والفيديوهات روابط خارجية؛ لا توجد خدمة رفع/تحويل/استضافة وسائط أو قصص.
- لا توجد بعد متابعة/مركز إشعارات كامل أو خوارزمية توصية أو سلاسل ردود أو رفع واستضافة وسائط.
- لا توجد طلبات ودفع حقيقي أو لوحة بائع/مخزون.
- لا يوجد Git كامل أو فروع أو Pull Requests أو CI.
- لا يوجد مزود نموذج AI أو فهرس RAG.
- لا يوجد بناء APK أو توقيع أو اختبار جهاز في هذه البيئة.
