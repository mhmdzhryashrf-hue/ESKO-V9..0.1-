# متجر هياكل البوتات — ESKO V5.5

- العدد: 500 قالب بداية في 10 فئات.
- كل عنصر له معرّف ووصف وأوامر وكلمات مفتاحية ورد أساسي مخصص.
- ملفات المشروع تُولد من محرك آمن مشترك؛ لا تعني كثرة القوالب وجود 500 خادم مستضاف منفصل.
- منصات الربط: WhatsApp Business Cloud API وTelegram Bot API وDiscord API عبر موائمات رسمية. أي منصة أخرى تحتاج موائمًا رسميًا منفصلًا.
- مفاتيح الوصول تحفظ في متغيرات البيئة على خادم HTTPS ولا توضع في ملفات المتصفح أو مستودع عام.
- القوالب لا تجمع جهات الاتصال ولا تحذفها ولا ترسل رسائل جماعية أو غير مطلوبة.
- يجب إعداد Webhook الرسمي واختبار كل موائم وحساب قبل اعتبار البوت متصلًا.
