# ESKO OPEN HUB V5.6 — تحديث الحماية والأداء

## المضاف
- مركز حماية مستقل داخل الموقع.
- مراقبة محلية لأخطاء JavaScript ورفض Promise ومخالفات CSP وتغيّر الاتصال.
- فحص سلبي لترويسات HTTP المتاحة وموارد HTTP وسلامة الروابط وملفات JavaScript من نفس المصدر.
- محلل محلي قائم على قواعد ثابتة يعرض توصيات إصلاح؛ لا يدعي أنه نموذج توليدي أو أنه يصلح ملفات الخادم تلقائيًا.
- فاحص توافق للمتصفح؛ لا يفحص الفيروسات أو سلامة نظام الزائر.
- تشفير وفك تشفير ملفات يختارها المستخدم باستخدام AES-256-GCM وPBKDF2-SHA256 داخل المتصفح، بحد 25MB.
- Service Worker لتخزين ملفات الواجهة الثابتة ودعم استقبال Push عند ربط خادم الإشعارات.
- إشعار اختبار محلي بعد موافقة المستخدم، مع موائم اختياري للاشتراك بخدمة Push عند إعداد VAPID وAPI.
- 90 دالة مساعدة للمهام وDOM والذاكرة والصور والحركة والشبكة والقياس وإمكانية الوصول.
- إزالة PIN ثابت كان ظاهرًا في JavaScript؛ PIN في الواجهة لا يصلح مصادقة.
- رفع الحد الأدنى لكلمة المرور الجديدة والاسترجاع في الواجهة إلى 12 حرفًا وإضافة مؤشر إرشادي للقوة.

## حدود معلنة
- لا يوجد backend مرفق في هذا التحديث. الحسابات والجلسات وArgon2id وCSRF وrate-limit وMFA تحتاج خادمًا فعليًا.
- GitHub Pages يستضيف الملفات الثابتة ولا يشغّل خادم الحسابات أو إرسال الإشعارات أو مراقبة النظام.
- المساعد الأمني افتراضيًا محلي قائم على القواعد؛ لا يوجد نموذج AI توليدي مربوط ولا ترقيع تلقائي لملفات الإنتاج.
- فحص الزائر يراجع إمكانيات المتصفح ولا يكشف malware أو اختراق النظام.
- تشفير الملفات يدوي للملفات التي يختارها المستخدم؛ لا يشفر بيانات IndexedDB أو APK تلقائيًا.
- تعديلات Android الأصلية تحتاج مشروع Android/Keystore وبناء APK مستقلًا.
- 90 معالجًا هي دوال JavaScript مساعدة وليست 90 نواة CPU أو ضمان تسريع مادي.
