# ESKO OPEN HUB V8.0 – TITAN UNIVERSE

## الأنظمة الجديدة

1. TITAN CORE: لوحة مركزية لمؤشرات المتصفح، تشخيص الوحدات وسجل الأحداث.
2. AI Factory: تحليل محلي لقصة المشروع، تقسيمها إلى صفحات ووظائف وخطوات، وتوليد هيكل بداية قابل للتنزيل.
3. Reality Builder: منشئ بصري بمكونات آمنة، تعديل النص والألوان، إعادة ترتيب وحذف، معاينة معزولة وتصدير HTML.
4. App Factory: قوالب PWA ولوحات تحكم ومعارض أعمال ومتاجر وصفحات هبوط، وتصدير ملفات بدء.
5. Code Review: مراجعة ثابتة للأنماط الشائعة في JavaScript وHTML وCSS وPython وSQL، دون تشغيل الكود.
6. API Market: كتالوج توثيق ومصادر عامة واختبار GET محدود مع HTTPS وCORS ووقت انتهاء.
7. AI Training Lab: مصنف كلمات تعليمي بسيط بأمثلة محلية.
8. Project Manager: مشاريع ومهام وتواريخ وحالات وتقدم محلي.
9. Team Workspace: سجل أعضاء وأدوار، استيراد وتصدير يدوي.
10. Design Engine: توليد لوحات ألوان وتصدير CSS.
11. Cloud Backup: تصدير واستعادة بيانات وحدات V8 فقط باستخدام AES-256-GCM وPBKDF2 عبر Web Crypto.
12. Titan Processors: 15 وحدة برمجية قابلة للتشخيص.

## المحركات الـ15

Titan Scheduler، Neural Task Router، Adaptive Render، Smart Cache، Memory Guardian، Project Index، Code Review Engine، Template Composer، Secure Storage، Backup Cipher، API Connector، Event Bus، Recovery Engine، Resource Monitor، Diagnostics Core.

## حدود التشغيل

- كل الوظائف الجديدة محلية في المتصفح، باستثناء طلبات GET العامة الاختيارية في API Market.
- AI Factory وAI Training ليسا نماذج ذكاء اصطناعي توليدية؛ الأول يبني خطة محلية والثاني مصنف تعليمي بسيط.
- Code Review هو فحص ثابت إرشادي وليس مترجمًا متكاملًا أو تدقيقًا أمنيًا شاملًا، ولا يشغل الكود.
- Team Workspace ليس تعاونًا لحظيًا بين الأجهزة؛ يتطلب ذلك خادمًا موثقًا.
- Cloud Backup ملف مشفر قابل للنقل وليس خدمة تخزين سحابية. لا يحوي بيانات الحسابات أو أسرار V7.x. فقد كلمة المرور تعني فقد القدرة على فك النسخة.
- API Market يرسل GET فقط إلى مصادر HTTPS العامة، وقد تمنع سياسة CORS بعض الاختبارات. لا تدخل مفاتيح سرية.
- جميع مؤشرات الذاكرة والتخزين تعتمد على ما يتيحه المتصفح ولا تمثل قياس CPU/GPU.
- التحديث خاص بالويب/PWA ولا يعدّل APK أو تطبيق Android الأصلي.
