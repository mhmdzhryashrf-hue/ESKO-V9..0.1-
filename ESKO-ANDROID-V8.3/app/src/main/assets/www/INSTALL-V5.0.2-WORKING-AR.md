# تثبيت تحديث ESKO V5.5 — عند اعتماد التحديث

1. احتفظ بنسخة احتياطية من مجلد `docs` الحالي.
2. استبدل ملفات `docs` بمحتويات مجلد `docs` من حزمة التحديث.
3. ارفع التغييرات إلى فرع `main` في المستودع الأساسي.
4. تأكد أن GitHub Pages ينشر من `main /docs`.
5. افتح الموقع في نافذة خاصة واختبر شاشة رمز الوصول، الخلفية، أزرار الدعم، مولّد أكواد البوتات، ومكتبة الأدوات.
6. اختبر كل موائم بوت على خادم مستقل باستخدام Sandbox أو حساب اختباري، ولا تضع مفاتيح API في GitHub أو الواجهة.
7. بعد نجاح الموقع فعليًا تبدأ فترة مراقبة الاستقرار 48 ساعة.

## الرمز

رمز الواجهة هو `103050`. تذكر أنه ظاهر داخل كود الموقع العام ولا يصلح كقفل أمني حقيقي على موقع ثابت. لا تستخدمه لحماية بيانات حساسة.
