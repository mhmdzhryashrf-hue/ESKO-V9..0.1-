# سجل تحديث ESKO OPEN HUB V5.8 — AI Developer Studio

## المزايا الجديدة
- ESKO AI Studio لأوضاع شرح المفاهيم ومراجعة الكود وتفسير الأخطاء وتخطيط المشاريع. الإجابة المحلية تعليمية وقواعدية. يمكن للخادم توفير `POST /api/ai/assist` مع موافقة المستخدم.
- مختبر HTML/CSS/JavaScript يعمل داخل iframe معزول بـ `sandbox="allow-scripts"` وسياسة CSP محلية تمنع الاتصالات الشبكية المعتادة. توجد مهلة إيقاف، لكن هذا ليس عزلًا على مستوى نظام التشغيل.
- أربعة مسارات تعلم (الويب، Python، الهاتف، AI والبيانات) مع حفظ تقدم محلي واختبارات قصيرة.
- مركز مراقبة المطور لتسجيل أخطاء الصفحة والاتصال محليًا وقائمة تحقق للنشر. لا يفحص الخادم أو الجهاز بحثًا عن برمجيات ضارة.
- ESKO Cloud محلي باستخدام IndexedDB، مع استيراد وتصدير. مزامنة الأجهزة اختيارية وتحتاج `POST /api/cloud/projects/sync` وموافقة المستخدم ومصادقة.
- متجر إضافات يثبت قوالب وصفية فقط؛ لا يشغّل JavaScript يرفعه المستخدم.
- 12 تحديًا برمجيًا بنقاط وشارات محلية. لا يوجد ترتيب عالمي دون خادم.

## حدود الإصدار
- GitHub Pages يستضيف ملفات الواجهة فقط؛ ميزات AI التوليدي والسحابة والحسابات/اللوحة العالمية تحتاج خادم API.
- المشاريع والإنجازات والإضافات محفوظة محليًا على هذا المتصفح فقط ما لم يتم تنفيذ backend.
- مختبر الكود مناسب للتجارب التعليمية الصغيرة فقط، وليس بديلًا عن Docker أو حاوية تشغيل معزولة. لا تشغّل شفرات غير موثوقة.
- لم يتم نشر هذا التحديث على GitHub أو اختباره على هاتف فعلي.
