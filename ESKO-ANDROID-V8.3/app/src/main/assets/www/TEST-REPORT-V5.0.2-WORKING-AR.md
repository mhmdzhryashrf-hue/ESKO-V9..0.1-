# تقرير فحص ESKO V5.5 — حزمة محلية غير منشورة

## فحوص آلية ناجحة
- JavaScript syntax check: `node --check docs/v5/esko-v5.js`
- JSON parse: `docs/v5/bots.json` و`docs/v5/tools.json`
- عدد قوالب البوتات: 160 (60 أصلية + 100 مضافة).
- عدد بطاقات الأدوات: 1600 (1000 أصلية + 600 مضافة في 10 مجموعات).
- قسم ذكاء الموقع يستخدم فهرس ESKO محليًا وتحليل نص داخل المتصفح، ولا يرسل النصوص تلقائيًا.
- زر دعم AI يستخدم `data-random-support` لتوجيه الرسالة عبر موزع الدعم الموجود.
- قسم المتجر يحتوي 30 بطاقة مع حالة «تحت التطوير».

## لم يتم اختباره
- لم يتم إجراء اختبار يدوي على متصفح Android أو Chrome.
- لم يتم اختبار Google Programmable Search لأن إعداد CX غير متوفر.
- لا يوجد نموذج LLM عالمي مجاني أو خدمة صوت إلى نص مدمجة؛ المساعد الحالي محدود بفهرس الموقع وتحليل النص الذي يلصقه المستخدم.
- لم يتم نشر الملفات على GitHub Pages.

## ملاحظات
فتح Google يتم في المتصفح الافتراضي، ولا يمكن لصفحة الويب إجبار Android على اختيار Chrome تحديدًا.
