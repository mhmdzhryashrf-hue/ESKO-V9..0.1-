# تركيب تحديث ESKO V7.0

1. احتفظ بنسخة احتياطية من مجلد `docs` الحالي.
2. فك ضغط حزمة V7.0 داخل جذر المستودع، بحيث يتم دمج مجلد `docs` مع الموجود.
3. راجع `git status --short` قبل أي commit.
4. افتح `docs/index.html` عبر خادم محلي أو GitHub Pages؛ بعض ميزات الصوت والتخزين تحتاج HTTPS.

الحزمة تخص الويب/PWA فقط، ولا تعدّل APK. لا تنشر إلا بعد مراجعة الملفات بنفسك.
