## الحدود الفنية
- جميع الميزات المضافة في V7.1 محلية داخل المتصفح، مع عدم الادعاء بوجود خادم مزامنة أو نماذج AI متصلة. AI Legion يولّد خطة تنظيم محلية بقواعد ثابتة، وليس عدة نماذج ذكاء اصطناعي مستقلة.
- شارات ومؤشر المهام يسجلان ضغط المستخدم على زر الإنجاز محليًا؛ لا يوجد تحقق خادمي من إنجاز المهمة ولا ترتيب عالمي.
- تشفير الخزنة يحتاج HTTPS أو localhost ومتصفحًا يدعم Web Crypto. كلمة المرور لا تُحفظ داخل النسخة؛ فقدانها يعني عدم القدرة على فك الملف.
- Voice Control يعرض اقتراحًا ولا ينفذ الأمر حتى يضغط المستخدم زر التأكيد.
- معاينة Builder تستخدم iframe معزولًا؛ لا يتم تنفيذ ملفات إضافات مستوردة.
- سجل Time Machine وCloud Vault محلي على نفس المتصفح/الجهاز، وليس نسخًا احتياطيًا خارجيًا.
- التحديث للويب/PWA فقط، ولا يعدّل APK أو يثبت تطبيقات على الجهاز.
