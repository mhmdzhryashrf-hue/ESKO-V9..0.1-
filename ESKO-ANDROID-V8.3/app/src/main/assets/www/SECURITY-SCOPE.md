# نطاق الحماية في ESKO V5.6

يرجى الرجوع إلى `SECURITY-BACKEND-REQUIREMENTS-V5.6-AR.md` للتفاصيل التنفيذية.

مركز الحماية في الواجهة يفحص إعدادات الصفحة والترويسات التي يستطيع المتصفح قراءتها، وموارد HTTP، وبعض مؤشرات ملفات JavaScript من نفس المصدر. كما يسجل أخطاء JavaScript ومخالفات CSP محليًا. لا توجد عمليات استغلال أو مسح منافذ أو تخمين كلمات مرور.

فاحص الزائر يقيس إمكانيات المتصفح فقط. لا يكشف البرمجيات الضارة ولا يستطيع إعلان أن الهاتف آمن. المحلل المحلي قائم على قواعد ثابتة ولا يساوي نموذجًا توليديًا، ولا يطبق إصلاحًا آليًا على ملفات الخادم.

تشفير الملفات يطبق على الملفات التي يختار المستخدم تشفيرها يدويًا عبر AES-256-GCM وPBKDF2 في متصفح آمن. لا يشفر تلقائيًا محتوى IndexedDB أو ملفات APK.

تسجيل الدخول العام، الجلسات، مراقبة الخادم، ترويسات الاستجابة، الإشعارات السحابية، وMFA تتطلب Backend واستضافة يديرهما مالك الموقع. GitHub Pages وحده لا يوفر هذه الوظائف.
