# 🃏 ESKO JOKER — الإضافة (حزمة دمج مستقلة)

هذه إضافة مستقلة لبوت واتساب قائم، وليست بديلًا عن مشروعك الحالي. صُممت حول معالج مركزي، أوامر منظمة، تخزين JSON، حماية للمجموعات، ألعاب قابلة للتوسيع، وقسم مشرفين.

## مهم بخصوص الأعداد
لا أصف 200 أمر أو 500 لعبة أو 400 ميزة بأنها مكتملة إذا لم تكن كذلك. هذه الحزمة تقدّم محركًا فعليًا قابلًا للتوسيع ومجموعة وظائف عاملة، مع مولّد فهارس/كتالوجات لا يدّعي أن العناصر غير الموجودة منفذة. يمكن إضافة المحتوى الحقيقي تدريجيًا من دون تضخيم أرقام وهمية.

## الملفات
- `index.js`: نقطة دخول الإضافة ومعالج مركزي.
- `core/processor.js`: ترتيب المعالجة ومنع التكرار والتعامل مع الأخطاء.
- `core/commands.js`: أوامر الترفيه والمشرفين والإعدادات.
- `core/moderation.js`: كشف الروابط، المنشن الجماعي، الإغراق، التحذيرات، حذف الرسائل، والطرد عند بلوغ حد التحذيرات.
- `core/games.js`: ألعاب أسئلة/ألغاز/تخمين ونظام نقاط.
- `core/utils.js`: تطبيع الرسائل ومعرّف المجموعة والمرسل.
- `store.js`: تخزين JSON بكتابة ذرية ونسخة احتياطية.
- `config.js`: الإعدادات الافتراضية.
- `connection.example.js`: مثال اختياري مستقل لعميل Baileys مع كود اقتران؛ لا تشغّله إذا كان بوتك متصلًا بالفعل.
- `test/smoke-test.js`: اختبارات أساسية.

## المتطلبات
Node.js 18+، وعميل واتساب لديك يوفّر `sock.sendMessage`. لا تحتاج الإضافة إلى أي حزمة خارجية ما دمت ستدمجها في عميلك الحالي.

## الدمج مع بوت موجود
انسخ مجلد `الإضافة` إلى جذر مشروعك. في ملف استقبال الرسائل الحالي، بعد إنشاء `sock`:

```js
const { createEskoAddon } = require('./الإضافة');

const eskoAddon = createEskoAddon({ sock });

// داخل مستمع الرسائل الحالي، بعد استلام message:
await eskoAddon.handleMessage(message);
```

إذا كان مشروعك يستخدم `messages.upsert`، فمرّر `msg` لكل عنصر من `upsert.messages` إلى `handleMessage`. لا تضف مستمعًا ثانيًا إذا كان لديك معالج بالفعل.

### تحديثات دخول الأعضاء
إذا كانت مكتبتك تدعم `group-participants.update`:

```js
await eskoAddon.handleParticipantsUpdate(update);
```

### صلاحيات مطلوبة
لكي يعمل الحذف والطرد، يجب أن يكون البوت مشرفًا في المجموعة، وأن تسمح مكتبتك بهذه العمليات. لا يمكن تجاوز صلاحيات واتساب.

## الأمان والسلوك
- إعدادات الحماية لكل مجموعة على حدة.
- الحذف والطرد قابلان للإيقاف من الإعدادات.
- حذف المخالفات والطرد التلقائي معطّلان افتراضيًا. لا تفعّلهما إلا بعد مراجعة القواعد، واختبارها، وموافقة مشرفي المجموعة؛ والطرد لا يحدث إلا بعد تجاوز حد التحذيرات وبشرط صلاحيات المشرف.
- قائمة الكلمات المسيئة في `core/moderation.js` افتراضيًا فارغة لتجنب فرض قائمة غير مناسبة على مجموعتك؛ أضف الكلمات التي تريد حظرها بنفسك.
- لا تخزن الإضافة رموز جلسات أو بيانات ربط داخل JSON.
- إذا تلف ملف البيانات، تُحفظ نسخة تالفة جانبية قبل ظهور الخطأ؛ لا يُستبدل الملف بصمت.

## الفحص
من داخل مجلد الإضافة:
```bash
node --check index.js
node --check core/processor.js
node --check core/commands.js
node --check core/moderation.js
node --check core/games.js
node --check store.js
node test/smoke-test.js
```

## مثال اتصال اختياري
`connection.example.js` مخصص فقط إذا كنت تريد إنشاء اتصال جديد من الصفر. إذا كان البوت الحالي متصلًا، لا تشغّله ولا تفتح جلسة ثانية على نفس الحساب. راجع الملف قبل الاستخدام، ولا تشارك مجلد `auth_info` مع أحد.
