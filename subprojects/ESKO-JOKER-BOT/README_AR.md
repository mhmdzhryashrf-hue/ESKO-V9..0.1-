# 🃏 ESKO JOKER BOT — الإصدار 1.0

بوت واتساب عربي ترفيهي وحمائي، مقسّم إلى وحدات ويستخدم JSON لحفظ الإعدادات والنقاط والتحذيرات.

## مهم قبل البدء
- هذا المشروع **لا يحتوي على كود تسجيل/ربط واتساب أو رمز اقتران**، حسب طلبك.
- لا يستبدل أي مشروع قديم؛ فك الضغط في مجلد مستقل.
- يوفّر وحدة `createBot({ sock })` لتوصيلها بعميل واتساب لديك بالفعل.
- الحماية لا تطرد الأشخاص تلقائيًا. حذف الرسائل المخالفة اختياري ومعطّل افتراضيًا، لتقليل الحذف الخاطئ.
- استخدم البوت في المجموعات التي تديرها، واحترم قواعد واتساب وخصوصية الأعضاء.

## المتطلبات
- Node.js 18 أو أحدث.
- عميل واتساب متوافق يوفّر `sock.sendMessage(...)`، وتوصله أنت في مشروعك الحالي.
- لا توجد حزم خارجية مطلوبة لهذه الوحدات.

## التثبيت والفحص على Termux
من داخل مجلد المشروع:

```bash
node --version
npm run check
npm test
```

لا يحتاج المشروع إلى `npm install` في هذه المرحلة لأنه يستخدم وحدات Node.js المدمجة فقط.

## الدمج مع اتصال موجود
في ملف استقبال الرسائل الموجود عندك، استورد الوحدة:

```js
const { createBot } = require('./ESKO-JOKER-BOT/src');

const eskoBot = createBot({ sock }); // sock هو عميل واتساب الموجود لديك بالفعل

// داخل مستمع الرسائل لديك، مرّر الرسالة بعد وصولها:
await eskoBot.handleMessage(message);
```

عدّل مسار `require` حسب مكان المجلد. لا تنشئ مستمعًا ثانيًا لنفس الرسائل إن كان مشروعك الحالي لديه مستمع بالفعل.

## الأوامر
- `!مساعدة` — قائمة مختصرة.
- `!منيو` — الأقسام.
- `!نكتة`
- `!لغز`
- `!سؤال` — سؤال معلومات عامة.
- `!نقاط` — نقاطك.
- `!ترتيب` — أفضل اللاعبين.
- `!تحذير @منشن السبب` — للمشرفين.
- `!اعدادات` — عرض إعدادات المجموعة للمشرفين.
- `!اعداد الترحيب تشغيل|إيقاف`
- `!اعداد الروابط تشغيل|إيقاف`
- `!اعداد منع_السب تشغيل|إيقاف`
- `!اعداد حذف_المخالفات تشغيل|إيقاف`
- `!ردود` — الردود المخصصة المسجلة.
- `!اضف_رد كلمة | الرد` — للمشرفين.
- `!حذف_رد كلمة` — للمشرفين.

## إعدادات الأمان
الإعدادات الافتراضية:
- الترحيب: تشغيل.
- منع الروابط: إيقاف.
- فلتر الكلمات المسيئة: تشغيل، بقائمة بسيطة قابلة للتعديل.
- حذف الرسائل المخالفة: إيقاف.
- حد الرسائل السريعة: 6 رسائل خلال 8 ثوانٍ، ثم تنبيه فقط.
- لا يوجد طرد تلقائي، ولا جمع بيانات خارج ما يحتاجه البوت للميزات.

عدّل `src/config.js` وقائمة `BAD_WORDS` في `src/core/moderation.js` بما يناسب مجموعتك. الفلاتر النصية ليست مثالية وقد تخطئ؛ راجعها واختبرها.

## النسخ الاحتياطي
تُحفظ البيانات في `data/esko-data.json` مع كتابة ذرية ونسخة احتياطية قبل التعديل. يمكنك عمل نسخة إضافية يدويًا:

```bash
mkdir -p "$HOME/ESKO-JOKER-BACKUPS"
cp -a data "$HOME/ESKO-JOKER-BACKUPS/data-$(date +%Y%m%d-%H%M%S)"
```
