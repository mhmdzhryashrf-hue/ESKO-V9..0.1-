# تثبيت تحديث ESKO OPEN HUB V5.6

هذه حزمة Patch لملفات الويب داخل مجلد `docs` فقط. لا تنشر التغييرات تلقائيًا ولا تعدّل APK.

## قبل الدمج
1. احتفظ بنسخة من مجلد `docs` الحالي.
2. فك ضغط ملف Patch في جذر المستودع بحيث تُدمج الملفات داخل `docs/`.
3. راجع التغييرات قبل النشر باستخدام `git diff -- docs`.
4. افحص JavaScript وJSON، ثم اختبر الصفحة على HTTPS وهاتف فعلي.
5. لا تنشر قبل ربط backend آمن للحسابات إذا كانت الحسابات العامة مطلوبة.

## ملاحظات مهمة
- إزالة بوابة PIN الثابتة مقصودة؛ أي رمز داخل JavaScript العام يمكن قراءته ولا يحمي البيانات.
- القفل المحلي الموجود إعداد واجهة على هذا المتصفح فقط، وليس مصادقة حساب أو تشفيرًا للملفات.
- مركز الحماية يستخدم فحصًا سلبيًا محليًا. لا يختبر استغلال الثغرات ولا يراقب نظام تشغيل الزائر.
- المساعد الأمني يعمل بقواعد محلية. يمكن ربط endpoint اختياري في `window.ESKO_SECURITY_AI_ENDPOINT` من الخادم نفسه؛ لا تضع مفتاح AI في JavaScript.
- تسجيل الدخول لا يصبح قويًا بمجرد مؤشر كلمة المرور. يلزم تطبيق متطلبات `SECURITY-BACKEND-REQUIREMENTS-V5.6-AR.md` على الخادم.
- اختبار الإشعارات محلي. Push عن بُعد يحتاج VAPID server-side و`POST /api/notifications/subscribe` وإرسالًا من الخادم.
- تشفير الملفات يخرج ملف `.esko.enc`؛ احتفظ بعبارة المرور في مكان آمن. الحد 25MB. لا ترسل عبارة المرور لأي شخص.
- 90 معالجًا هي وظائف برمجية مساعدة للواجهة وليست أنوية معالج حقيقية.
- دمج Android الأصلي موضح في `ANDROID-SECURITY-INTEGRATION-V5.6-AR.md`؛ لا توجد ملفات APK أو مشروع Android في هذه الحزمة.
