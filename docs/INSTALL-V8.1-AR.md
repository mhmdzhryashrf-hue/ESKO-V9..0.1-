# تركيب ESKO V8.1 في Termux

1. احتفظ بنسخة احتياطية من مجلد `docs` الحالي.
2. فك ضغط حزمة V8.1 فوق جذر المستودع المحلي؛ الحزمة تحتوي مجلد `docs/`.
3. افحص `git status --short` وراجع `docs/CHANGELOG-V8.1-AR.md`.
4. ارفع التغييرات إلى GitHub Pages يدويًا فقط بعد مراجعتك.

هذه حزمة ويب/PWA وليست APK.
