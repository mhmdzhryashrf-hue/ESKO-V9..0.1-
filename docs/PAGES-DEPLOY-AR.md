# نشر ESKO OPEN HUB V5.0.1 على GitHub Pages

1. من إعدادات المستودع افتح **Settings → Pages**.
2. اختر **Deploy from a branch** ثم الفرع `main` والمجلد `/docs`.
3. ارفع محتويات هذا المجلد إلى مجلد `docs` في المستودع، مع استبدال الملفات القديمة.
4. انتظر نجاح `pages build and deployment` ثم افتح رابط الموقع.

**مهم:** GitHub Pages يستضيف ملفات ثابتة فقط. حسابات المستخدمين والمناقشات تحتاج نشر `backend/server.mjs` على استضافة تدعم Node.js، ثم ضبط `window.ESKO_API_BASE` على عنوان API الصحيح مع إعداد CORS وHTTPS. لا تضع مفاتيح أو كلمات مرور في ملفات `docs`.

لم يتم تعديل Android في هذا التحديث؛ يبقى مؤجلًا حتى مرور 48 ساعة من الاختبار دون أخطاء مؤثرة.
