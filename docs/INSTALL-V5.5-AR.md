# تثبيت تحديث ESKO OPEN HUB V5.5

هذه حزمة تحديث لملفات الويب داخل مجلد `docs` فقط. لا تغيّر ملفات Android ولا تنشر شيئًا تلقائيًا.

## المتطلبات
- المستودع المحلي `ESKO-OPEN-HUB-V5.0` أو نسخة حديثة منه.
- Git وTermux.
- أن يكون مصدر GitHub Pages مضبوطًا على `main /docs`.

## خطوات التطبيق عند طلب التحديث
1. خذ نسخة احتياطية من مجلد `docs` الحالي.
2. فك ضغط الحزمة في جذر المستودع، مع الإبقاء على مسارات `docs/...`.
3. راجع التغييرات أولًا باستخدام `git diff -- docs`.
4. بعد المراجعة نفّذ `git add docs` ثم `git commit` ثم `git push`.
5. افتح تبويب Actions وتأكد من اكتمال نشر Pages، ثم اختبر الموقع على الهاتف.

## ملاحظات مهمة
- 160 قالبًا أساسيًا و500 قالب متجر لا تعني وجود بوتات مستضافة ومتّصلة. يلزم إعداد بيانات المنصة الرسمية وWebhook وخادم HTTPS لكل بوت.
- قوالب البوت تعرض 12 ملفًا، بينها 3 وحدات مساعدة للذكاء: قاعدة معرفة محلية، محلل نصوص، وموائم اختياري لمزود خارجي. مفاتيح المزود تحفظ على الخادم فقط.
- متجر الألعاب يحوي 100 إدخال؛ 12 منها تستعمل محركات محلية موجودة، و88 إدخالًا موسومًا تحت التطوير.
- الأشكال الهندسية والإضافات تحفظ محليًا في المتصفح. لا يحدث تثبيت مباشر داخل APK أو مزامنة عبر الحساب من دون backend وجسر Android.
- معالجات الأداء تنظّم عمل JavaScript والرسوم؛ لا ترفع قدرة CPU الفعلية أو سرعة الشبكة.
- قفل `103050` قفل واجهة تجريبي وليس حماية للبيانات الحساسة.
- لم تُختبر الحزمة على هاتف فعلي ولم يتم نشرها من داخل هذه الحزمة.
