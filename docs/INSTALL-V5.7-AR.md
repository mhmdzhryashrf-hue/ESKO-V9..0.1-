# تثبيت تحديث ESKO OPEN HUB V5.7

1. احتفظ بنسخة احتياطية من مجلد `docs` الحالي.
2. فك ملف التحديث فوق مجلد المشروع مع السماح باستبدال الملفات داخل `docs`.
3. تأكد من وجود الملفات `docs/v5/education.js` و`docs/v5/education-catalog.json`.
4. افتح الموقع من خلال HTTPS أو localhost، ثم حدّث الصفحة تحديثًا كاملًا. رقم Cache في Service Worker تغير إلى V5.7.
5. افتح القائمة الجانبية ثم **قسم التعليم والبرمجة**.

## تشغيل مدرس AI توليدي حقيقي (اختياري)
المدرس الموجود يعمل محليًا بقواعد تعليمية. لربط نموذج AI:
- أنشئ endpoint خاصًا بالخادم مثل `/api/education/assistant`.
- اجعل الخادم يتحقق من الطلبات ويحدد الحجم ومعدل الاستخدام ويتعامل مع أخطاء المزوّد.
- خزّن مفتاح AI في متغير بيئة على الخادم فقط، ولا تضعه في `app.js` أو `education.js` أو أي ملف عام.
- عيّن `window.ESKO_EDUCATION_API = '/api/education/assistant'` قبل تحميل `v5/education.js`، واختبر الرد بصيغة JSON تحتوي حقل `answer` نصيًا.
- لا ترسل كلمات مرور أو مفاتيح أو بيانات شخصية في أسئلة المساعد.

الحزمة الحالية لا تحتوي على endpoint خلفي أو مفتاح مزود AI؛ لذلك لا تدّعي تفعيل نموذج توليدي خارجي قبل نشر الخادم وربطه.
