# تقرير اختبارات ESKO OPEN HUB V5.0.1

## اختبارات اجتازت
- `node --check public/app.js`
- `node --check public/v5/esko-v5.js`
- `node tests/check-package.js`
- `node tests/smoke-test.mjs`
- `node tests/v5-integration.mjs`

## ما تم التحقق منه
- 1000 بطاقة كتالوج في 10 أقسام.
- 60 قالب بوت معرّفًا وبدون تكرار.
- 51 لعبة في الفهرس، منها 11 محركًا محليًا جاهزًا.
- وجود ملف صورة المقدمة والمقطع الصوتي وروابطهما في الواجهة.
- تدفق الحسابات والجلسات والاسترجاع وخصوصية الجلسات في اختبارات الخادم.
- المناقشات العامة والمجموعات والرسائل الخاصة والحظر والإبلاغ وانتهاء الرسائل بعد 7 ساعات في اختبارات الخادم.

## ما لم يتم التحقق منه بعد
- نشر النسخة الجديدة على GitHub Pages من حساب مالك المستودع.
- تجربة فعلية على الهاتف بعد النشر، بما فيها تشغيل الصوت واللمس.
- تشغيل الحسابات والمناقشات عبر API مستضاف خارجيًا؛ لم يتم إعداد استضافة API أو CORS في هذه المهمة.
- اختبار متواصل لمدة 48 ساعة.
- بناء أو اختبار APK؛ ملفات Android تُركت دون تعديل.
