# تثبيت تحديث ESKO OPEN HUB V5.0.1

## تحديث موقع GitHub Pages

1. فك ضغط `ESKO-OPEN-HUB-V5.0.1-WEB-PATCH.zip` في مجلد جديد.
2. انسخ محتويات مجلد `docs` من الحزمة إلى مجلد `docs` داخل نسخة المشروع الموجودة في Termux، مع استبدال الملفات القديمة.
3. افتح Termux ونفّذ من داخل مجلد المشروع الحالي:

```bash
cd ~/storage/downloads/ESKO-OPEN-HUB-V5.0
git add docs
git commit -m "Update ESKO V5.0.1 web patch"
git push
```

4. من GitHub افتح Actions وتأكد من نجاح `pages build and deployment`. يجب أن يظل مصدر Pages هو `main` والمجلد `/docs`.
5. افتح رابط الموقع واختبر القائمة والواجهة والألعاب والأصوات.

## حدود مهمة قبل اختبار اليومين

- GitHub Pages لا يشغّل Node.js API. التسجيل والمناقشات يحتاجان نشر `backend/server.mjs` على خدمة Node.js منفصلة مع HTTPS وإعداد CORS و`window.ESKO_API_BASE`. لا يوجد خادم حي تم إنشاؤه أو ربطه بهذه الحزمة.
- اللعبة التجارية الظاهرة في الصورة لم تُنسخ ولم تُدمج؛ أضيفت لعبة ESKO Sky Dash أصلية وغير قتالية بدلًا منها.
- أزرار الدعم تفتح القناة الرسمية العامة. لم يُنشر رقم هاتف مباشر داخل ملفات الموقع لتجنب عرض رقم شخصي علنًا.
- لم يتم تعديل مجلد Android أو بناء APK. ابدأ فترة الاستقرار 48 ساعة فقط بعد نشر الموقع واختباره فعليًا.
- انشر الصوت المرفوع فقط إذا كنت تملك حق استخدامه.
