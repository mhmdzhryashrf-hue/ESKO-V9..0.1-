# سجل تغييرات ESKO OPEN HUB V5.5 — نسخة عمل غير منشورة

- استخدام صورة Joker التي رفعها صاحب المشروع كخلفية للواجهة، مع حركة بطيئة وطبقة عينين متحركة بشكل خفيف.
- إضافة شاشة رمز وصول بعد انتهاء المقدمة؛ الرمز المحدد `103050`.
- تحويل قوالب البوتات الستين إلى مولّد ملفات قابل للنسخ، مع إخفاء الكود افتراضيًا وإتاحة عرضه عند الحاجة.
- إضافة أربع بطاقات لكل قالب: قناة المطور، وصف البوت، زر الدعم برسالة جاهزة تتضمن بيانات القالب، وكيفية الاستخدام.
- إضافة موائمات API رسمية لـ WhatsApp Business Cloud وTelegram وDiscord كملفات قوالب قابلة للتخصيص، مع رسالة دعم مسبقة بمعلومات البوت وشاشة اتصال ملوّنة بعد نجاح Webhook.
- إضافة عشرين مؤشر/مجموعة أداء في قسم البوتات، مع أدوات عملية في `performance-core.js`.
- مراجعة تحميل أدوات الموقع بحيث يقرأ `tools.json` بدل استخدام متغير غير معرّف؛ المكتبة تضم 1000 بطاقة في 10 أقسام.
- الحفاظ على لعبة البقاء الخيالية غير القتالية `ESKO Survival Arena` في أول قسم الألعاب.
- عدم إضافة حذف جهات اتصال أو جمعها تلقائيًا أو إرسال جماعي غير مطلوب.

## حدود مهمة

قفل `103050` قفل واجهة فقط لأن GitHub Pages ينشر ملفات JavaScript للزوار؛ لا يعتبر حماية حقيقية للأسرار أو المحتوى. للحماية الفعلية يلزم تحقق من الخادم.

هياكل البوتات قوالب برمجية جاهزة للنسخ وليست بوتات متصلة فورًا. يلزم خادم HTTPS ومفاتيح رسمية وWebhook واختبار لكل منصة. WhatsApp Cloud API يعرض روابط نصية، وقد لا يعرض أربع بطاقات خضراء كأزرار أصلية.

هذه النسخة لم تُرفع إلى GitHub ولم تُنشر؛ تحتاج اختبارًا على الهاتف بعد الرفع.

- توسيع قسم البوتات من 60 إلى 160 قالبًا (إضافة 100 قالب جديد).
- توسيع مكتبة الأدوات من 1000 إلى 1600 بطاقة (إضافة 600 بطاقة موزعة على 10 أقسام).
- إضافة قسم ذكاء ESKO محدود النطاق: البحث في فهرس الموقع، وتحليل النص/تفريغ الكلام محليًا، ورسالة واضحة للأسئلة خارج النطاق. لا يدّعي وجود نموذج عالمي مجاني مدمج.
- تحسين البحث: زر لفتح نتائج Google في تبويب المتصفح الافتراضي؛ عرض النتائج داخل الصفحة عبر Google Programmable Search يتطلب CX.
- إضافة قسم متجر إلكتروني بخلفية Joker و30 بطاقة معالجة/أداة، مع تنبيه «تحت التطوير» وعدم تفعيل الدفع.
