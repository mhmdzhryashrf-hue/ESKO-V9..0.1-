# تقرير الاختبار — ESKO V5.6

## اختبارات الملفات
- فحص تركيب JavaScript بـ `node --check` للملفات المعدلة والجديدة.
- محاولة تشغيل Chromium headless محليًا لم تنتهِ ضمن المهلة بسبب تعطل بيئة المتصفح؛ لذلك لم يُسجل اختبار واجهة مرئي ناجح.
- فحص JSON الخاص بالـ manifest وملفات بيانات V5.5 السابقة.
- فحص HTML للتأكد من عدم تكرار معرفات العناصر وربط عناصر مركز الحماية.
- التحقق من أن سجل الأداء يعرض 90 دالة فريدة موزعة على 8 مجموعات.
- التحقق من غياب رمز PIN الثابت من ملفات الواجهة النشطة.
- اختبار بناء/فك بيانات التشفير على مستوى صيغ البيانات واختبار مشتق مفتاح AES-GCM باستخدام Web Crypto.
- اختبار ضغط الحزمة وقراءة محتوياتها.

## غير مختبر أو يحتاج خدمة فعلية
- لا توجد قاعدة بيانات أو Backend مرفق، لذلك لم يتم اختبار تسجيل دخول حقيقي أو جلسات أو rate limiting أو CSRF أو Argon2id.
- لم يتم اختبار إرسال Push من خادم؛ المتاح إشعار محلي فقط حتى ضبط VAPID وAPI.
- فحص الأمان لا يثبت خلو الموقع من الثغرات ولا يفحص نظام الزائر.
- لم يتم تشغيل اختبار متصفح مرئي ناجح في هذه البيئة، ولم يتم اختبار الهاتف أو Android APK.
- ترويسات HTTP الفعلية لا يمكن فرضها من Patch ثابت على GitHub Pages؛ يجب قياسها بعد النشر.

## مستوى الثقة
الاختبارات هنا ساكنة ومحلية. لا يُعد التحديث شهادة أمنية أو تدقيق اختراق أو موافقة جاهزية للإنتاج. يجب ربط الخادم، مراجعة الترويسات، ثم الاختبار على بيئة HTTPS فعلية قبل استقبال حسابات حقيقية.
