# متطلبات الخادم الاختيارية لـ V8.0

هذه الوظائف لا تعمل عبر GitHub Pages وحده:

- AI Factory بنموذج توليدي: API وسيط مصادق عليه، مفاتيح مزود محفوظة في متغيرات البيئة، حدود استخدام، سجل طلبات منقح من البيانات الشخصية، مهلات، وسياسة محتوى. لا تُرسل مفتاح المزود إلى المتصفح.
- Team Workspace: قاعدة بيانات، هوية وجلسات، صلاحيات لكل مشروع، دعوات منتهية الصلاحية، حماية CSRF عند استخدام Cookies، وتسجيل تدقيق.
- Cloud Sync: تخزين كائنات خاص بالمستخدم، تشفير أثناء النقل والتخزين، قواعد احتفاظ، نسخ احتياطي واستعادة مختبرة.
- API Market الخاص: قائمة سماح للوجهات، proxy لتجنب كشف الأسرار، تحديد معدل الطلبات والتحقق من الاستجابة.
- نشر التطبيقات: بيئة بناء معزولة، فحص مكونات، موافقات نشر، وبيئة تشغيل منفصلة.

لا تعتبر هذه الوثيقة تنفيذًا للخادم؛ إنها حدود الربط قبل إضافة الخدمات الفعلية.
