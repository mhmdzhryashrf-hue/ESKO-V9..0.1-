# ESKO OPEN HUB V5.0.1 — تحديث الويب

## ما تغير
- استبدال رسم المقدمة بصورة نسر أصلية محسّنة للويب.
- إضافة المقطع الصوتي المقدم كمعاينة اختيارية ومقتطف قصير لأصوات الواجهة، مع بقاء الصوت اختياريًا.
- توضيح أن تسجيل الحسابات والمناقشات يحتاجان خادم API منفصلًا؛ GitHub Pages لا يشغّل الخادم.
- إضافة فحص فعلي لقدرات الواجهة والملفات والحركة والتخزين والاتصال، دون ادعاء تسريع CPU أو الشبكة.
- إضافة 10 هياكل بوتات جديدة (الإجمالي 60).
- إضافة لعبة متصفح أصلية غير قتالية باسم ESKO Sky Dash، تعمل باللمس ولوحة المفاتيح.
- تحسين استجابة الأزرار للمس ولوحة المفاتيح واحترام إعداد تقليل الحركة.
- توجيه أزرار الدعم إلى القناة الرسمية العامة بدل نشر رقم هاتف شخصي.

## ملاحظات مهمة
- لم تُدمج ملفات لعبة تجارية أو تُنسخ واجهتها أو محركاتها.
- لم يتم تعديل أو بناء نسخة Android؛ مرحلة Android مؤجلة حتى اجتياز اختبار استقرار الويب لمدة 48 ساعة.
- لا تُعد قوالب البوتات أو بطاقات الأدوات خدمات تشغيلية قبل ربطها واختبارها.
- التسجيل والمناقشات لن يصبحا متاحين على GitHub Pages قبل إعداد خادم API آمن وربطه عبر `window.ESKO_API_BASE`.
- يجب نشر المقطع الصوتي فقط إذا كان لديك حق استخدامه.
