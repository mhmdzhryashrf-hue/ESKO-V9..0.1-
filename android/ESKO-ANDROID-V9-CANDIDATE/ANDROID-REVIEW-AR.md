# مراجعة مرشح Android ESKO V9.0.2 — واجهة الأقسام الستة

هذه شجرة مصدر مرشحة وليست APK نهائيًا. تم الحفاظ على معرّف التطبيق `com.esko.openhub`، و`versionName=9.0.2` و`versionCode=11` كقيم مصدر مرشح لا كإصدار مبني ومثبت. جرى تحديث أصول WebView المضمّنة لتعرض الشريط السفلي الثابت بالترتيب:

1. البيت
2. المتجر الإلكتروني
3. المستودعات
4. المساعد
5. الأقسام
6. الحساب

## التنفيذ

- الواجهة المضمّنة داخل `app/src/main/assets/www/` متزامنة مع واجهة الموقع ذات الأقسام الستة.
- ملفات HTML/CSS/JavaScript المضمنة اجتازت `node --check` وفحص الموارد المحلية.
- `AndroidManifest.xml` قابل للتحليل كـ XML، ويتضمن HTTPS-only (`usesCleartextTraffic=false`)، وتعطيل النسخ الاحتياطي، وRTL، و`adjustResize` للوحة المفاتيح.
- `MainActivity` يستخدم `WebViewAssetLoader`، ويعطّل File/Content access والمحتوى المختلط، ويستخدم Safe Browsing، ويسمح بالموقع البعيد فقط عبر HTTPS وعلى أصل محدد.

## الحدود

- التطبيق ما زال حاوية WebView وليس تطبيقًا Native كاملًا.
- وضع الملفات المحلية يعرض الواجهة فقط؛ الخلاصة والحساب والمستودعات والكتالوج تحتاج خادم ESKO حقيقيًا.
- يتطلب الاستخدام الشبكي نشر الموقع والـAPI على أصل HTTPS واحد، أو إعداد CORS منفصل والتحقق منه.
- المساعد المضمّن محرك قواعد محلي لا نموذجًا توليديًا.
- لا توجد Gradle أو Gradle Wrapper أو Android SDK أو `sdkmanager` أو `adb` في بيئة التدقيق؛ لم يتم بناء APK/AAB أو توقيعه أو تثبيته أو اختباره على جهاز.
- لا يُعتمد هذا المرشح للتوزيع أو التحديث على تطبيق مثبت حتى يُبنى ويُوقّع بمفتاح المالك وتُطابق شهادة التوقيع ونسخة التطبيق المثبتة.
